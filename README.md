# NAU Course Data

## Data files
- `nau_courses.csv` - Raw scraped course list with descriptions when available.
- `nau_courses_ai.csv` - Filtered subset of courses with AI-related mentions in the description.

## Notes
- I only scraped the subject prefixes listed in `prefixes.txt`.
- Some courses do not have descriptions on the catalog results pages, so the dataset does not include every course description.
